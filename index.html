    Plan schema v1.2

    JSON Schema, draft 2020-12. The planner's output is produced by constrained decoding against this schema, so every plan it returns conforms: only registered tools, an origin for every parameter, citations for every inferred value, uncertainty that is always propagated, and a refusal that names the input when one is missing.
